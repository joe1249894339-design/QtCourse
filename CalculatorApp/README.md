# Qt 计算器（支持键盘事件）

一个参考 iPhone 深色风格的桌面计算器，支持四则运算、小数、退格、清除，并支持键盘与鼠标混合输入。

## 运行方式

1. 用 Qt Creator 打开 `Calculator.pro`（Qt 5.12 及以上，或 Qt 6 均可，需要带 Widgets 模块）。
2. 选择编译器套件（MinGW 或 MSVC），点击运行（Ctrl+R）。

> 提示：界面全部用代码（`QGridLayout` + `QVBoxLayout`）构建，不依赖 `.ui` 文件，打开 `.pro` 即可编译运行。
> 如果你需要在「UI 设计器」中看到同样的布局，可以把 `buildUi()` 里的网格布局手动拖成相同的
> 5×4 网格——本实现用代码布局是为了把「布局原理」和「信号槽/键盘逻辑」放在同一处、便于阅读。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `main.cpp` | 程序入口，创建并显示主窗口 |
| `calculator.h` | 主窗口类声明：状态机、处理函数、控件 |
| `calculator.cpp` | 界面构建 + 全部计算逻辑 + 键盘事件 |

## 键盘映射

| 键盘 | 功能 |
| --- | --- |
| `0`~`9`（含小键盘） | 输入数字 |
| `+` `-` `*` `/`（含小键盘） | 加 / 减 / 乘 / 除 |
| `.` 或 `,` | 小数点 |
| `=` 或 回车（Enter / 小键盘 Enter） | 等号 |
| 退格（Backspace） | 退格 |
| `Delete` 或 `Esc` | 全部清除 |

## 需求对应与设计说明

### 1. 鼠标与键盘复用同一套逻辑（需求 4）
按钮的 `clicked` 信号和窗口的 `keyPressEvent` **最终都调用同一组函数**
（`inputDigit / inputDecimalPoint / inputOperator / inputEquals / backspace / clearAll`），
因此两种输入方式行为完全一致，混合输入（点几下按钮、再敲几下键盘）也不会出错。

为保证键盘事件始终到达窗口，所有按钮设置为 `Qt::NoFocus`，窗口设置为 `Qt::StrongFocus`
（见 `createButton()` 与构造函数）。

### 2. 状态机统一处理边界情况（需求 3、6）
用四态状态机描述输入流程：

- `EnteringFirstNumber`：输入第一个操作数
- `AfterOperator`：已按操作符，等待第二个操作数
- `EnteringSecondNumber`：输入第二个操作数
- `ResultShown`：已显示结果

各边界情况在状态机内天然成立：

| 情况 | 处理方式 |
| --- | --- |
| 连续小数点 `1 . . 5` | 输入串已含 `.` 时忽略，结果为 `1.5` |
| 连续操作符 `5 + ×` | 后一个操作符覆盖前一个 |
| 连续运算 `2 + 3 ×` | 先算 `2+3=5`，再以 5 作为新左操作数 |
| 除数为 0 | 显示「错误」，需按 `AC` 清除后才可继续 |
| 计算完成后继续输入数字 | 自动清零，开始全新计算 |
| 计算完成后继续按操作符 | 以结果作为左操作数继续运算 |
| 输入过程中退格 | 删除最后一位，删到空回到 `0` |
| 清除后重新计算 | `AC` 完全复位所有状态 |

### 3. 显示输入、操作符与结果（需求 3）
- 副显示（上方小字）显示进行中的表达式，如 `12 +`、`12 + 5 =`。
- 主显示（下方大字）显示当前输入的数字或最终结果。

### 4. 消除浮点尾差（需求 6 相关）
结果用 `QString::number(value, 'g', 15)` 格式化，使 `0.1 + 0.2` 显示为 `0.3`
而不是 `0.30000000000000004`。

## 已知简化（非缺陷）
- 未实现百分比 `%`、正负号切换 `±`、以及「连续按等号重复上次运算」等功能，题目未要求。
- 运算按「从左到右」顺序执行（与 iPhone 一致），不做运算符优先级（如 `2+3×4=20` 而非 14）。
