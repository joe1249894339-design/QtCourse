# 3 分钟测试视频脚本

录屏分辨率建议 1920×1080，提前把系统通知关掉；打开 `bin\TextEditor.exe`，
用 `demo\sample.txt` 作为演示文件。语速正常即可，不需要逐字念稿。

## 0:00–0:20 开场

- 画面：主窗口 `sample.txt - 编辑器`。
- 口播/字幕：这是 Qt 多窗口文本编辑器，菜单和工具栏由 Action Editor 创建，
  左侧行号、当前行高亮、底部状态栏已生效。
- 鼠标依次指一下：文件 / 编辑 / 格式 / 查看 / 帮助，以及工具栏的 4 个分组。

## 0:20–0:50 新建、编辑、撤销/重做

- `Ctrl+N` 新建窗口，输入两行文字。
- 观察标题出现 `*`。
- `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 恢复。
- 选中一段文字，`Ctrl+X` 剪切、`Ctrl+V` 粘贴；再 `Ctrl+C`/`Ctrl+V`。
- 鼠标打开“编辑”菜单，展示剪切/复制/粘贴的使能状态随选区变化。

## 0:50–1:20 保存/打开/未保存提示

- `Ctrl+S` 保存到 `demo\demo_saved.txt`（或任意路径）。
- 再输入一个字，让标题出现 `*`。
- 点击窗口关闭按钮，出现“保存 / 不保存 / 取消”：
  - 先点“取消”，窗口保留；
  - 再关闭，点“保存”，文件保存后关闭。
- 重新打开刚保存的文件，说明“打开”会复用空白窗口，内容不丢。

## 1:20–1:45 查找/替换

- `Ctrl+F` 打开查找，输入 `one`，点“查找下一个”两次，展示连续查找。
- 输入一个不存在的词，点查找，展示“未找到”提示。
- `Ctrl+H` 打开替换，全部替换 `one` → `1`，展示“共替换 3 处”。
- `Ctrl+Z` 一次撤销，恢复原文。

## 1:45–2:10 字体/颜色/行号/自动换行/背景

- 选中第一行，打开“格式→字体”，改为加粗、16pt；再设字体颜色/字体背景色。
- “格式→编辑器背景色”选深蓝，展示文字和行号自动变浅色。
- 关闭/打开“显示行号”，关闭/打开“自动换行”，展示状态栏提示和水平滚动条。
- “查看”菜单取消勾选工具栏、状态栏，再恢复。

## 2:10–2:40 边界与异常

- 打开 `demo\binary.bin`，展示“该文件包含二进制数据，可能不是文本文件”，
  当前文档不变。
- 打开一个不存在的路径（可在文件对话框里输入不存在的文件名），展示提示。
- `Ctrl+N` 再开一个窗口，打开 `demo\second.txt`，展示两个窗口并排/切换。
- 说明自动保存：已有路径的文件默认每 60 秒自动保存，可在文件菜单关闭。

## 2:40–3:00 GitHub 与收尾

- 切到 GitHub 仓库的 Commits 页面，或 `git log --oneline --graph --decorate`
  的终端画面，展示 8–10 条分阶段提交。
- 回到程序，画面停在主界面，结束。

## 录制后检查

- 视频中至少出现：新建/打开/保存、修改未保存提示、查找或替换、撤销/重做、
  1 个异常或边界场景、Git 提交历史。
- 确认没有把 `sample.txt` 改坏；需要的话重新从压缩包解压 `demo` 目录。
